# Changelog

## 0.1.1

- Turn the Search button into a Stop button while QMD is running.
- Terminate the complete QMD process group when a search is stopped.

## 0.1.0

- Initial public release.
- Search QMD indexes with hybrid, keyword, and vector modes.
- Filter searches with configurable collection checkboxes.
- Open ranked results at their source lines.
- Configure result typography, layout, spacing, and snippet length.
